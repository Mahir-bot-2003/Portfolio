Computer Vision / MLOps / Full-Stack AI

EdgeSafety-AI — Real-Time PPE & Safety Detection System

A production-oriented PPE compliance monitoring system built on a 3-model YOLOv8 ensemble with a 14-class unified detection registry. The system identifies helmets, gloves, vests, goggles, masks, and hazardous events in real time at 30+ FPS via live webcam feeds, with a FastAPI web dashboard for live streaming and static image analysis.

  • Engineered a 3-model ensemble with custom cross-model IoU/IoM NMS filter to resolve overlapping detections across all 14 classes.
  • Achieved 94.3% mAP@50 (helmet) and 94.1% mAP@50 (glove) after 100-epoch AdamW training on RTX 4050.
  • Implemented 30-frame temporal smoothing buffer with IoU-based tracking to eliminate label flickering.
  • Built complete FastAPI web dashboard with real-time MJPEG streaming, dynamic PPE target isolation, live detection stats, and interactive training metric charts.
